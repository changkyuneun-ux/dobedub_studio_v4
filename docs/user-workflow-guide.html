USER WORKFLOW GUIDE

사용자 업무 흐름 기준 화면 순서

로그인부터 영상 결과 확인, 이력·자산 관리, 관리자 운영까지 — DOBEDUB STUDIO를 처음 쓰는 사람이 "다음에 뭘 눌러야 하는지" 한눈에 알 수 있도록 실제 화면 순서대로 정리했습니다. 카드를 누르면 해당 화면으로 이동합니다(로그인 상태가 필요합니다).

제작 흐름 · 전체 사용자
HELP · 언제든 접근 가능
운영 · 관리자 전용
1
진입 로그인 · 상태 확인

사내 계정으로 로그인하면 시작됩니다. 궁금한 점이나 시스템 이상이 의심될 때는 언제든 HELP 메뉴(User Manual · System Status · Metadata)로 돌아올 수 있습니다.

6a로그인
사내 계정 ID·비밀번호로 접속합니다. 외부 SSO는 없습니다.
전체 사용자/studio/access/login
6bUser Manual
화면별 사용법과 세그먼트 규칙을 문서 내 검색으로 바로 찾을 수 있습니다.
manual:read/studio/access/manual
6cSystem Status
ComfyUI·Qwen 엔드포인트 상태를 미리 확인합니다. HELP 소속이라 관리자 화면으로 전환되지 않습니다.
system:read/studio/admin/status
7g차단 · 만료 · 오류
403 권한 없음 · 401 세션 만료 · 공통 오류는 별도 메뉴가 아니라, 해당 상황이 생기면 자동으로 표시됩니다.
전체 사용자
2
생성 준비 STEP 1 / 4 · 이미지 로드

워크플로를 고르고 키프레임 이미지를 올리면, 이미지 수에 맞춰 세그먼트 수가 자동으로 정해집니다(n−1). 예전에 만든 프롬프트나 자산을 재사용하려면 이 단계에서 미리 열어봐도 됩니다.

2a이미지 로드
워크플로 선택 → 키프레임 업로드. 필수 슬롯을 모두 채워야 다음 단계로 넘어갑니다.
workflows:read/studio/create/load
4cPrompt Library
재사용 등록된 프롬프트를 검색해 워크스페이스에 적용합니다.
prompts:reuse/studio/review/reuse
5aAssets
과거 키프레임·결과물에서 자산을 미리 확인합니다.
history:read/studio/review/assets
3
세그먼트 설정 STEP 2 / 4 · 세그먼트마다 반복

Keyword Builder에서 Positive/Negative 카탈로그를 조합하거나 직접 입력해 프롬프트를 만들고, 같은 화면 오른쪽에서 세그먼트별 Wan Node Config(스텝·CFG·모션 등)와 seed를 설정합니다. 규칙 위반·필수 누락 경고는 화면 상단에 모아서 보여줍니다.

2b프롬프트 설정
Keyword Builder · 직접 입력 · 규칙 위반/필수 누락 경고. Positive/Negative는 각각 접고 펼치는 아코디언입니다.
prompts:build/studio/create/prompt
2e노드 컨피그 & seed
세그먼트별 파라미터와 seed(자동/직접 입력). 2b와 같은 화면의 오른쪽 패널입니다.
jobs:run/studio/create/prompt
4
실행 STEP 3 / 4 · 단일 작업 제출

모든 세그먼트 설정을 표로 마지막 확인한 뒤 Run을 누르면 작업이 제출됩니다. 진행 중에는 상태와 로그를 실시간으로 보여주고, 취소를 누르면 재제출을 막고 "Cancelling…" 상태로 바뀝니다.

2f실행 전 전체 구성 확인
세그먼트 표 · 제출 검증 · payload 확인 후 Run.
jobs:run/studio/create/confirm
2c생성 진행
상태 인포그래픽 · 로그 · 취소 요청(Cancelling). 진행 중에는 세그먼트별 부분 결과는 제공되지 않습니다.
jobs:run/studio/create/progress
5
결과 확인 STEP 4 / 4 완료 시 우측 상단 토스트 알림

작업이 끝나면(완료·실패·취소) 화면 어디에 있든 우측 상단에 토스트로 알려줍니다. 실행 직후에는 이 화면에서 바로 결과를 확인하고, 평가·재사용 등록·재실행은 다음 단계인 Task History에서 이어서 할 수 있습니다.

2d실행 직후 결과
Final 병합본 + 구간 검수본 미리보기와 다운로드.
jobs:run/studio/create/result
3f · 3cRun 상세 · 평가/재실행
완료 결과 평가·재사용 등록, 실패 원인 확인은 별도 화면이 아니라 다음 단계 Task History 우측 패널로 통합됐습니다.
prompts:review
6
이력 · 자산 관리 되돌아보기와 재작업

지난 작업을 다시 찾아보고, 완료작은 평가·재사용 등록을, 실패작은 원인 확인과 재실행을 할 수 있습니다. 자산은 컬렉션 필터로 정리해 다음 작업에 다시 가져다 씁니다.

3aTask History
목록 + 미리보기 · 20건 페이지네이션 · 우측 패널에서 Overview/Assets/Node Config/Prompt Review 확인, 평가·재사용 등록·재실행·삭제까지 여기서 처리합니다.
history:read/studio/review/history
5aAssets
키프레임 · 구간 영상 · Final 결과물을 컬렉션별로 모아 봅니다.
history:read/studio/review/assets
6e알림 센터
별도 목록 화면 대신, 작업이 끝나는 순간 화면 우측 상단 토스트로 안내합니다(6초간 표시).
전체 사용자
7
운영 · 관리 Admin 전용 · 좌측 사이드바 상단 "관리자 콘솔 →"

권한 설계, 사용자 관리, 프롬프트 카탈로그·워크플로 정의, Sandbox Pod, 감사 로그까지 운영에 필요한 모든 화면입니다. 권한이 없는 항목은 사이드바에 아예 보이지 않습니다.

3b역할 & 권한
역할별 권한 매트릭스를 편집하고 일괄 저장합니다.
roles:read/studio/admin/roles
7b기능 리소스 매핑
화면·API ↔ 필요 권한 코드 대조표(조회 전용).
roles:read/studio/admin/resource-map
3e사용자 관리
사용자 목록에서 역할을 배정합니다.
users:read/studio/admin/users
7c사용자 상세
개별 추가 권한 부여, 비밀번호 초기화, 비활성화.
users:write/studio/admin/users/detail
4e카탈로그 계층
그룹 → 서브카테고리 → 용어 구조와 노출 순서를 관리합니다.
prompt-catalog:write/studio/admin/catalog/hierarchy
3d용어 관리
개별 용어 CRUD. 4e와 같은 트리에서 이어서 편집합니다.
prompt-catalog:write/studio/admin/catalog/terms
4bNegative 기본값
모든 워크플로에 공통 적용되는 네거티브 용어를 추가합니다.
prompt-catalog:write/studio/admin/catalog/negative-defaults
7a시스템 프롬프트
프롬프트 생성 LLM 지시문 편집, 버전 이력과 되돌리기.
prompt-catalog:write/studio/admin/system-prompt
4a워크플로 정의
등록된 워크플로 조회, Activate/Deactivate.
workflows:read/studio/admin/workflows
4d워크플로 등록
신규 워크플로 JSON 등록·갱신 단일 저장 폼.
workflows:write/studio/admin/workflows/register
5bSandbox Pod
워크플로 시험 실행용 Pod 시작/정지.
sandbox:control/studio/admin/sandbox
6dMetadata
워크플로 widget metadata 조회·재생성. HELP 소속이라 관리자 화면 전환 없이 접근됩니다.
metadata:read/studio/admin/metadata
A-04감사 로그
권한·사용자·카탈로그 변경, Sandbox 제어 이력 조회.
roles:read/studio/admin/audit-log
